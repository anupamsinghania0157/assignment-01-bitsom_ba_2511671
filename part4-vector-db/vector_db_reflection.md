## Vector DB Use Case

A traditional keyword-based database search is not sufficient for searching large legal contracts. Keyword search relies on exact word matching, which fails when different wording or synonyms are used. For example, a query like "termination clauses" may not match if the document uses phrases like "contract ending conditions".

Vector databases solve this problem by using embeddings that capture the semantic meaning of text. Instead of matching exact words, they compare the meaning of the query with the stored documents. This allows more accurate and relevant results.

In the case of a law firm, contracts can be converted into embeddings and stored in a vector database. When a user asks a question in plain English, the system converts the query into an embedding and retrieves the most similar sections of the contract.

This enables intelligent search, improves efficiency, and allows lawyers to quickly find relevant information in large documents. Therefore, vector databases play a critical role in building semantic search systems for legal applications.
